# Adaptation Insights (prototype)

Static copy of the Adaptation Insights website prototype, published with GitHub Pages from this branch.
The pages come from the Design canvas export; `support.js` renders them in the browser. The data is the pilot dataset of 18 November 2026
(8 projects, not yet reviewed). The pipeline code is on the `main` branch.

## Languages

The interface is available in English, French and Spanish through `i18n.js`. The selected language is stored in the browser and carried across pages. Interface labels and controlled categories are translated; evidence statements and downloaded source data retain their original wording.
